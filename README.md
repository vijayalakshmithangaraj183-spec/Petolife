# PetOlife Digital Identity

##  Overview
This project presents a simplified launch homepage for a "Digital Pet Identity" system.

The goal is to make a complex concept feel simple, useful, and accessible for pet owners and veterinarians.

---

##  Key Features
- Clean and simple UI
- Digital Pet Identity generation (demo)
- AI-based health insights (rule-based)
- Smooth user flow

---

##  Product Thinking
Pet care data is fragmented. This solution introduces a unified identity system that:
- Stores pet data in one place
- Helps track health and ownership
- Enables future integrations with vets and shelters

---

## AI Approach
A lightweight AI logic is implemented using rule-based conditions:
- Age-based health suggestions
- Demonstrates how AI can assist pet care decisions
